大洲市の名前が出た記事は、約10年ぶんの4分の1が、たった1か月に集まっていた

メモう

「大洲市」の名前が出た記事を、約10年ぶん数えたら1,619本。

そのうち399本が、2018年7月の1か月に集まっとった。

愛媛の外のサイトが大洲の名前を書くんは、ふだん月に5本なんやって。

3行でいうと調べた資料 6本

  • 日本語の記事に「大洲市」が出てくる本数は、2017年1月から約10年で1,619本。そのうち399本が2018年7月の1か月に集まっていた
  • 愛媛の外のサイトが大洲市の名前を書くのは、ふだん月に5本。2018年7月は269本で、2か月後の9月は22本だった
  • 同じ数え方で八幡浜市は891本、いちばん多い月は7.2％。4分の1が1か月に集まるのは、どの市でも起きることではなかった

ニュースに大洲市の名前が出るのは、どんなときか。

世界のニュースを集めて数えている、民間のデータがある。日本語の記事も入っている。そこで「大洲市」が出てくる記事を、約10年ぶん数えた。1,619本あった。

月ごとに並べると、1か月だけが飛びぬけていた。2018年7月。西日本豪雨の月である。この1か月に399本。全体の4分の1が、ここに集まっていた。

どうやって数えたのか

GDELTというデータで、機械が英語に訳した文の中から「Ozu City」を探した。

GDELTは、アメリカの研究者が始めた民間のプロジェクトである。世界中のニュースのサイトを見て回り、記事を集めている。公式の説明には、こうある。

In short, GDELT monitors news coverage from across the world, machine translates all of the coverage it sees in 65 of those languages into English and then allows you to search those machine translations.

The GDELT Project Blog「GDELT DOC 2.0 API Debuts」

世界中の報道を見て、65の言語の記事をすべて機械で英語に訳し、その訳文を探せるようにしている、という意味だ。日本語の記事も、英語に訳されてから探される。だから「大洲市」は、「Ozu City」という語で探すことになる。

さかのぼれるのは2017年1月1日まで。数えたのは、そこから2026年10月1日までの9年9か月である。この記事では「約10年」と書く。

データは、だれでも無料で使ってよい。条件は、GDELTの名前とリンクを付けることである。

4分の1が、1か月に集まっていたのか

集まっていた。1,619本のうち399本、24.6％が2018年7月だった。

年ごとの本数を並べる。

2018年を月ごとに見ると、こうなる。

6月の21本が、7月に399本になった。いちばん多い日は7月13日の40本である。

117か月を多い順に並べると、真ん中の月は5本しかない。1本も当たらなかった月も11ある。1日ごとに見ると、3,529日のうち2,751日は0本だった。ふだんは、ほとんど名前が出ない。

それは本当に、愛媛の大洲の記事なのか

名字の「小津」や滋賀県の「大津」と分かる記事は、1本も無かった。ただし、16％は見出しだけでは決められなかった。

「Ozu」は、別のものにも当たりそうな語である。そこで、見出しとURLが取れた1,613本を、1本ずつ分けた。記事の本文は開いていない。見出しと、どのサイトかだけで分けた。

分けた結果本数割合
愛媛の大洲の話と読める1,349本83.6％
別の「Ozu」と分かる0本0％
見出しだけでは決められない264本16.4％

「City」を付けて探したので、人の名字は外れている。分け方は、見出しの語とサイトで決めた荒いものだ。語の選び方で、割合は数ポイント動く。決められなかった264本は、見出しに地名が入っていない記事である。全国の天気のまとめや、新聞の地域面の短い記事が多い。

分けていて、もう1つ分かったことがある。見出しに「大洲」や「肱川」の字がある記事は、1,613本のうち227本しか無い。残りは、記事のどこかに大洲市の名前が1回出てくるものだ。県内のライフラインの情報の一覧、県ぜんたいの記事、全国のまとめ。「大洲市のニュース」というより、「大洲市の名前が出た記事」と呼ぶほうが正しい。

2018年7月の399本も、全部が豪雨の記事ではない。同じ月の全国の猛暑の記事にも、大洲市の名前が出ている。

あの月、だれが大洲の名前を書いたのか

愛媛の外のサイトである。ふだんは月に5本なのに、この月は269本だった。

1,613本を、愛媛の地元の新聞と放送局のサイトと、それ以外に分けた。地元が742本、それ以外が871本になる。

愛媛の外のサイトは、豪雨の前の半年は月に5.0本。7月は269本で、53.8倍になった。地元のサイトは7.8倍である。7月に大洲市の名前を書いたサイトは、数えると37あった。公共放送、全国紙、通信社、経済紙、ほかの県の新聞が並ぶ。

この月は、全国が大洲の名前を書いた月だった。

そのあと、どうなったのか

愛媛の外のサイトの本数は、2か月でふだんの水準に近づいた。

8月が66本、9月が22本、10月が17本。7月の269本と比べると、9月は12分の1である。

これを「2か月で忘れられた」と書くのは、言いすぎになる。記事が減ったことと、人の関心が減ったことは、同じではないからだ。そこで、別の2つの数字と並べた。ウィキペディアの「大洲市」のページが開かれた回数と、国会で豪雨のあとの大洲や肱川が語られた回数である。

ウィキペディアは、ふだんから月に3,300回ほど読まれている。7月はその4倍になり、9月にはほぼ元に戻った。記事と同じ形である。

国会だけ、形が違う。9月と10月は0件で、11月に10件に戻る。国会は、開いている月にしか発言が無い。臨時国会が始まると、また語られた。翌年の2019年6月にも、11件ある。年ごとに数えると、2018年が32件、2019年が26件。1年たっても、8割が残っていた。

記事とウィキペディアは、すぐ引いた。国会は、時間をおいて何度も戻ってきた。国会の数え方は西日本豪雨のあと、国会は大洲を69回語った。総理大臣が2回名前を挙げたのは「三善地区」だったに、ウィキペディアは「大洲市」のウィキペディアがいちばん読まれた日は、甲子園の日だった。約11年分の閲覧数を1日ずつ数えたに書いた。豪雨そのものと裁判のことは、あの豪雨の裁判で、大洲の防災はどう変わるのかにある。

ほかの市でも、同じ形になるのか

ならない。八幡浜市で同じ数え方をすると、いちばん多い月は全体の7.2％だった。

「Yawatahama City」で探すと、同じ期間に891本。いちばん多い月は同じ2018年7月だが、64本である。2番目に多い月は38本で、差は小さい。

豪雨の前の年、2017年の本数は、大洲市が302本、八幡浜市が262本。ふだんの量は、ほとんど同じだった。1か月に4分の1が集まるのは、大洲市のほうだけである。

西予市は、この数え方では数えられなかった。「Seiyo City」で探すと、約10年で0本になる。機械が「西予市」をこの語に訳していない、と見られる。

年ごとの本数が減ったのは、関心が冷めたからなのか

そうとは言えない。数える側が、拾わなくなった分が大きい。

年ごとの本数は、2019年の190本から、2024年の31本まで減っている。これを「大洲への関心が冷めた」と読みたくなる。でも、3つの理由で、そうは読めない。

1つめ。GDELTが1年に見ている記事の総数そのものが、減っている。2017年は約2億2,800万本、2025年は約5,600万本。4分の1になった。

2つめ。愛媛の地元の2つのサイトの記事が、ほとんど拾われなくなった。

この数は、見出しが取れた1,613本で数えた。地元のサイトは、2017年の200本が、2021年には5本になった。地元の新聞や放送局が、大洲の記事を書かなくなったはずはない。GDELTの側が拾えなくなった、と考えるほうが自然である。理由は分からなかった。

3つめ。豪雨の山が無い八幡浜市も、同じ形で減っている。2017年の262本が、2023年には13本になった。

愛媛の外のサイトだけを見ると、2020年より後は年に20本から40本ほどで、あまり動いていない。月に2、3本。これが、ふだん全国が大洲の名前を書く量である。

この数え方は、どこが弱いのか

機械の訳に頼っていること。そして、同じ記事を何度も数えていること。

公式の説明も、訳の誤りを認めている。

As with all machine translation systems, you are bound to find numerous errors in its results

The GDELT Project Blog「GDELT Translingual: Translating the Planet」

どの機械翻訳とも同じで、結果には数多くの誤りが見つかるはずだ、という意味である。「大洲市」が「Ozu City」と訳されなかった記事は、数に入らない。何本あるのかは、分からない。別の訳し方を1つ試すと、「Osu City」は約10年で3本だった。

数えているのは、記事ではなくURLである。通信社の記事が各地の新聞に載れば、その数だけ数える。見出しの頭の24字が同じものをまとめると、1,613本は1,350種類になった。

データが無い日もある。約10年のうち32日ぶんは、GDELTの側に数字が無かった。

調べても分からなかったこと

  • 見出しだけでは決められなかった264本が、本当に大洲の記事かどうか
  • GDELTが、愛媛の地元のサイトを拾わなくなった理由
  • GDELTが、日本のニュースの何％を拾っているのか
  • 「大洲市」と書いてあるのに、数に入らなかった記事の本数

数えてみて

ふだん、愛媛の外で大洲市の名前が書かれるのは、月に5本ほどだった。それが269本になる月が、約10年に1度だけあった。名前が広く書かれたのは、いちばん大変だった月である。

もう1つ分かったのは、数えるデータの側にも波があることだ。年ごとの本数だけを見ていたら、「関心は冷めた」と書くところだった。減っていたのは、関心より先に、拾われる記事の数だった。
