大洲の学校の体育館にエアコンはあるのか。教室は99.6%、体育館は0%だった

メモう

学校の教室のエアコンは、もうほとんど全部に付いとるんよ。

でも体育館はゼロ。大洲だけじゃなくて、愛媛の市町の半分がゼロなの。

市はこれから8年がかりで入れていく計画なんだって。

3行でいうと調べた資料 16本

  • 公立小中学校の普通教室の空調設置率は 99.6%。だが体育館等は全国で31.7%
  • 文科省の市区町村別データでは、大洲市の学校体育館は0%。愛媛20市町のうち11が0%
  • 大洲市は令和8年度に設計を始め、令和15年度まで8年がかりで20校に入れる計画だ

教室は99.6%。体育館は31.7%

学校のエアコンの話は、ふつう「教室」の話だ。そして教室の話は、もう終わっている。

文部科学省が令和8年7月30日に公表した調査（令和8年5月1日現在）によると、公立小中学校の普通教室の空調設置率は 99.6% だった。全国380,623室のうち378,955室。ほぼ全部に付いている。

だが同じ日に公表された体育館の調査は、まったく違う数字を出している。

体育館等（小学校は体育館、中学校は体育館・武道場）の設置率は 31.7%。全国31,878棟のうち10,099棟だ。3棟に1棟しかない。

99.6%と31.7%。同じ学校の敷地の中に、67.9ポイントの差がある。

教室がどう進んだかを見ると、この差の意味が分かる。文科省の推移グラフによれば、普通教室の設置率は平成22年10月に16.0%、平成29年4月に49.6%、平成30年9月に58.0%だった。それが令和元年9月に77.1%、令和2年9月に92.8%と一気に跳ね、令和8年5月で99.6%に達した。平成30年9月から令和2年9月までの2年で、34.8ポイント上がっている。 体育館にはその急坂がまだ来ていない。

愛媛県は23.1%。そして大洲市は0%だった

この調査には都道府県別の表が付いている。愛媛県の行はこうだ。体育館及び武道場が 441棟、そのうち空調があるのが 102棟、設置率 23.1%。全国平均の31.7%を8.6ポイント下回る。

ただ、県の平均を見ても大洲のことは分からない。同じ調査には 市区町村別のグラフ も付いていて、41ページ目が愛媛県だった。棒グラフの左から8本目が大洲市で、棒は立っていない。

大洲市 0%。

県内20市町を全部読むと、こうなっていた。

  • 100% … 今治市、四国中央市、鬼北町
  • 66.7% … 松前町 / 36.4% … 東温市 / 33.3% … 伊方町
  • 10.0% … 愛南町 / 7.7% … 八幡浜市 / 2.8% … 新居浜市
  • 0% … 松山市、宇和島市、西条市、大洲市、伊予市、西予市、上島町、久万高原町、砥部町、内子町、松野町

20市町のうち11が0%だった。 県庁所在地の松山市も0%だ。愛媛県の23.1%という数字は、県内が平均的に2割そろっているという意味ではない。全部付けた3市町と、1棟も付いていない11市町に割れている。 平均値がいちばん実態から遠くなるタイプの分布だった。

全国が9ポイント伸びた年に、愛媛は1.3ポイントだった

気になったのは伸び方のほうだった。

1年前の調査（令和7年5月1日現在）を開いて、同じ欄を見比べてみた。愛媛県は445棟のうち97棟で 21.8%。そのときの全国は22.7%。差は0.9ポイントしかなく、愛媛県はほぼ全国平均だった。

それが1年で、全国は22.7%から31.7%へ 9.0ポイント 上がり、愛媛県は21.8%から23.1%へ 1.3ポイント 上がった。差が0.9ポイントから8.6ポイントに広がった計算になる。棟数でいえば、愛媛県で空調が付いた体育館は97棟から102棟へ、1年で5棟増えただけだ（445棟から441棟への減りは、統廃合などで調査対象から外れた分だと考えられる）。

止まったのではない。全国が急に走り出した年に、愛媛県はそれまでの速さで歩いていた。

大洲市の記録では、7年前も「42施設すべてなし」だった

では大洲市はいつから0%なのか。市議会の会議録を「空調」で検索すると、2019年（令和元年）9月定例会に、はっきりした答弁が残っていた。避難所となる体育館へのエアコン設置を問われた市側の答えだ。

「指定避難所のうち、市が管理する体育館は42施設 あり、その全てにおいてエアコンは整備されていない状況でございます」

理由も同じ答弁にある。指定避難所の空調は総務省の緊急防災・減災事業債のメニューにはあるが、「体育館は広く、天井も高いことから、全ての体育館においてエアコンを整備するには、かなりの事業費を要することになる」。他の事業との優先度を踏まえて慎重に検討する、という結びだった。

同じ2019年9月定例会の委員会報告には、もっと具体的な言葉がある。改築中だった八多喜地区の屋内運動場について避難所としての暑さ対策を問われた市側は、こう答えている。

「屋内運動場については 室内容積が多く、設備費、電気代も多額となることから空調設備は整備をしていない。しかし、今年度〔＝2019年度〕校舎の教室等に空調設備を整備することとしているので、暑さがひどいときには 校舎の教室等を利用していただくことも可能 としている」

体育館を冷やす代わりに、冷えている教室へ移ってもらう。当時の答えはこれだった。

なお大洲市の教室のエアコンは、平成30年12月の補正予算で一気に入っている。国の「ブロック塀・冷房設備対応臨時特例交付金」を使い、小中学校の普通教室と特別教室、幼稚園の保育室と遊戯室に設置し、工事の完成は平成31年度中を見込む、と当時の議案説明にある。全国の教室が急坂を上ったあの2年と、ぴたり重なっている。

なぜ体育館だけ後回しになるのか

答えは「容積」と「断熱」の2つだ。

容積のほうは分かりやすい。教室は40人が入る箱だが、体育館はバスケットコートが入る箱で、天井も高い。冷やすべき空気の量が桁で違う。市の答弁が繰り返し「室内容積が多く」と言っているのはこの意味だ。

やっかいなのは断熱のほうだ。国が作った 空調設備整備臨時特例交付金（屋内運動場の空調設備整備事業）には、「避難所に指定されていること」と「断熱性が確保されること」という2つの補助要件がある。エアコンだけ入れても、屋根と壁から熱が入り続ける建物では効かないからだ。

どれくらい違うのか。文科省が令和5年9月に出した試算がある。東京にある延床面積930平方メートルの体育館を想定した数字で、こうなっている。

  • 断熱なしで空調だけ入れる場合 … 工事費 3,900万円、必要な冷房能力128kW（室外機2台・室内機8台）、電気代 年280万円
  • 断熱改修をしてから空調を入れる場合 … 断熱4,000万円＋空調2,600万円で 計6,600万円、必要な冷房能力70kW（室外機2台・室内機5台）、電気代 年140万円

断熱すると、必要な冷房能力が 128kWから70kWへ半分近くまで落ちる。だから空調本体が安くなり、電気代も年280万円から140万円へ半分になる。初期費用は2,700万円高くつくが、15年目の空調更新の時点で断熱工事費を回収でき、40年で 5,500万円 安くなる、というのが文科省の計算だ。

つまり体育館の空調は、エアコンを買う話ではなく、建物の外皮を作り直す話になる。1校あたり数千万円が、そこで動く。

大洲市がこの要件をどう受け止めたかは、令和7年3月定例会の市長答弁に出ている。

「市内の小中学校20校全ての体育館が今回の交付金の対象 となり、そのうち 断熱性がある程度確保されている体育館は、現在のところは小学校3校、中学校2校 になっております」

20校のうち、すぐ空調工事に入れそうなのは 5校 だけ。残る15校は断熱から手を付けることになる。同じ答弁では、ランニングコストも含めて「断熱工事の内容、空調工事の方式、電気式かガス式か」を専門家に聞きながら検討する、とも述べられている。

大洲市の計画は、令和15年度まで8年がかり

その検討の結果が、令和7年11月25日の全員協議会で示された「大洲市学校施設長寿命化計画」の改定だった。学校体育館の空調整備は、令和8年度を設計1期、令和9年度を工事1期として、令和15年度の工事7期まで8年間で進める、という内容だ。

令和7年12月定例会で、8年は長すぎないか、2年でも3年でも前倒しできないか、と問われた教育長は、理由を2つ挙げている。

「整備期間を8年間としている理由につきましては、1校につき断熱工事も含め多額の工事費用がかかる ことから、財政負担の平準化を図るため、交付金の最終年度である令和15年度までを目標としています」

もう1つは工期だ。「学校運営に支障を来さないよう円滑に実施するために、主要な工事を夏季休業中に行う必要があり、同時期に工事が重なった場合、施工業者の入札不調や人員不足による工事遅延も考慮し、年間2校から3校での整備が妥当」。前倒しは現時点では困難だが、工期の短縮には努めたい、という答弁だった。

体育館の工事は夏休みにしかできない。だから1年に打てる手は2〜3校ぶん。20校を割れば、それだけで7〜8年になる。

第1期の2校も決まっている。大洲南中学校と大洲北中学校だ。教育長の答弁によれば、南海トラフ地震対策も想定し、「各地域の避難所の状況や想定される避難者数を考慮の上」で選ばれた。令和8年3月定例会の市長の施政方針でも、令和8年度にこの2校の設計に着手すると述べられている。第2期以降の学校は、令和7年12月の時点では決まっていない。

止まるものもある。令和8年3月定例会で学校トイレの洋式化について問われた教育部長は、こう答えている。「まずは空調整備を優先して実施していきますので、校舎等の大規模な長寿命化工事については一旦休止していく ということになります」。市内小中学校の洋式トイレ設置率は全便器588基のうち380基で64.6%、洋式化率40%台の学校が5校あるが、校舎の大規模改修に合わせたトイレ改修は当面動かない、ということだ。体育館の空調という1つの決定が、同じ敷地の中の別の順番を押し下げている。

国は令和8年8月に、目標を2年前倒しした

ここで国のほうが動いた。

文科省が令和8年9月2日付で更新した資料に、経緯が書かれている。令和8年7月31日の熱中症対策に関する関係閣僚会議で、高市総理が学校体育館などのエアコン設置率について「2035年までに100%」の目標の前倒しを指示。8月27日の会議で松本文部科学大臣が、令和9年度からの5年間で加速化策を講じ「令和13年度中に設置率を100%とすることを新たな目標にしたい」と報告し、総理が「令和17年度中に100%」から「令和13年度中に100%」への前倒しを決めた。

大洲市の計画の完了は令和15年度。国の新しい目標は令和13年度。 現行の8年計画のままだと、国の目標より2年遅く終わる勘定になる。

そして、加速化策として文科省が挙げた3つのうちの1つが「長期休み以外の工事事例や、費用対効果のよい工事事例など好事例の周知」だった。夏休みに工事が集中するという、大洲市が8年かかる理由に挙げたまさにその点を、国も詰まりどころとして見ている。

補助の条件も確認しておく。この交付金は補助率2分の1、地方負担分には100%地方債を充てられ、その元利償還金の50%に交付税措置がある。実質の地方負担は25%。 対象工事費は下限400万円、上限1.1億円（電気式）または1.4億円（ガス式）。対象期間は令和15年度まで。令和7年度から体育館の空調の光熱費にも普通交付税措置が入った。断熱工事は空調と別の年度でもよい。

令和8年9月の市議会には、空調の質問が3人から出ている

令和8年9月の大洲市議会（第4回定例会）の発言通告書を見ると、空調に関する質問が3人の議員から出ている。

  • 後藤ともなり議員「学校教育の充実と学校施設の防災機能について」のうち「学校体育館の空調整備の早期化について」
  • 梅木加津子議員「災害から市民生活を守るために」のうち「避難施設の空調設置について」
  • 笹木健吾議員「大洲市のスポーツ施設について」のうち「屋内スポーツ施設のエアコン・スポットクーラーの設置状況について」

3人とも切り口が違う。学校施設、避難所、スポーツ施設。だが見ているのは同じ「屋内の広い空間」だ。

調べていて意外だったのは、この問いが新しくないことだった。平成30年12月の定例会でも、教室にエアコンが入ることを評価した議員が、続けて「今後屋内運動場へのエアコン設置は、災害時には避難所にもなるため、引き続きの検討が必要と考えます」と質している。同じ問いが8年近く議場で繰り返され、計画ができたいま、工事が全部終わるまでにもう8年かかる。

数字を並べてみて残ったのは、体育館という建物の厚みだった。教室に99.6%までエアコンが届いた同じ敷地で、数十メートル離れた体育館が0%で止まっている。その差を作っているのは意欲や関心ではなく、桁の違う容積と、外皮を作り直すという工事の重さと、夏休みという40日間の短さらしい。避難所として体育館へ行く日のことを考えると、そこはまだ、外の空気とほとんど同じ温度の建物だ。
